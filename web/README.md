# MG Business Web

نسخه وب مستقل MG Business؛ یک پلتفرم مرورگرمحور و PWA برای مدیریت کسب‌وکارها، با دو هسته مستقل و کنترل‌شده.

## ساختار اصلی محصول

**سازنده MG → کسب‌وکار → کاربران کسب‌وکار → مشتریان کسب‌وکار**

1. **هسته سازنده MG:** پنل محرمانه مالک پلتفرم برای مدیریت کسب‌وکارها، مجوزها، اشتراک‌ها، ماژول‌ها، زیرساخت، پایگاه‌داده‌ها، انتشارها، امنیت و سلامت کل سیستم.
2. **هسته کسب‌وکار:** فضای مستقل هر کسب‌وکار برای مدیریت شعب، کاربران و دسترسی‌ها، فروش، سفارش، کالا و انبار، مشتریان، حسابداری و ماژول‌های تخصصی.
3. **صفحه مشتری:** فروشگاه/پرتال عمومی هر کسب‌وکار؛ مشتری فقط محتوای منتشرشده و اطلاعات متعلق به خودش را می‌بیند.

## ساختار داده

**پایگاه‌داده مرکزی MG → پایگاه‌داده مرکزی مستقل هر کسب‌وکار → داده محلی هر کاربر روی هر دستگاه**

پایگاه‌داده مرکزی MG اطلاعات مدیریتی پلتفرم و ارجاع امن به پایگاه‌داده کسب‌وکارها را نگه می‌دارد. هر کسب‌وکار پایگاه‌داده عملیاتی مستقل خود را دارد. اطلاعات محلی دستگاه صرفاً cache و صف عملیات آفلاین است؛ مرجع قطعی فروش، موجودی، حسابداری و مجوزها نیست و سرور هنگام همگام‌سازی همه چیز را دوباره اعتبارسنجی می‌کند.

## اجرای نسخه فعلی

```bash
cd web
npm install
npm run dev
npm test
npm run build
```

## وضعیت فعلی

نسخه موجود یک prototype تعاملی React/Vite است و داده‌های نمایشی را در localStorage نگه می‌دارد. این داده‌ها سروری، مشترک بین کاربران یا مناسب عملیات واقعی نیستند. تا زمان تکمیل API، احراز هویت و پایگاه‌داده‌های مرکزی، از آن برای ثبت فروش، اطلاعات واقعی مشتریان یا حسابداری استفاده نکنید.

## معماری هدف

- Frontend: React + TypeScript + Vite، PWA، طراحی واکنش‌گرا، فارسی RTL و انگلیسی LTR.
- Backend: ASP.NET Core Web API و worker به شکل modular monolith با مرزبندی کنترل‌پلین و کسب‌وکار.
- Data: PostgreSQL؛ پایگاه‌داده مرکزی MG و یک پایگاه‌داده منطقی مجزا برای هر کسب‌وکار.
- Identity: نشست امن، هویت سراسری، عضویت مستقل در هر کسب‌وکار، نقش‌ها و مجوزهای دقیق.
- Isolation: مسیریابی دیتابیس فقط در سمت سرور و کنترل دسترسی tenant/branch در تمام درخواست‌ها.
- Device sync: IndexedDB برای cache و outbox آفلاین با همگام‌سازی idempotent و حل تعارض.
- Deployment: کانتینری، TLS، مدیریت اسرار و پشتیبان‌گیری/بازیابی مستقل هر کسب‌وکار.
