# MG Business Web

نسخه وب پلتفرم یکپارچه MG Business؛ در کنار نسخه دسکتاپ و با حفظ دامنه قابلیت‌های آن توسعه داده می‌شود.

## اجرای محلی
```bash
cd web
npm install
npm run dev
```

## ساخت نسخه انتشار
```bash
npm run build
npm run preview
```

## انتشار آزمایشی
این برنامه با Vite ساخته می‌شود و خروجی استاتیک آن از طریق GitHub Actions قابل انتشار در GitHub Pages است. پس از فعال‌کردن Pages با منبع **GitHub Actions** در Settings → Pages و ادغام شاخه توسعه در main، انتشار خودکار انجام می‌شود.

نشانی مورد انتظار:
https://mahdi0383.github.io/MG-Business-Platform/

## وضعیت معماری و محدودیت محیط تست
GitHub Pages فقط فایل‌های استاتیک را میزبانی می‌کند؛ API، پایگاه داده مرکزی، ورود امن چندکاربره، همگام‌سازی شعب و عملیات حساس تجاری روی Pages اجرا نمی‌شوند. نسخه فعلی یک پیش‌نمایش تعاملی است و داده‌های آزمایشی را فقط در localStorage همان مرورگر نگه می‌دارد. این داده‌ها برای حسابداری یا استفاده واقعی قابل اتکا نیستند.

معماری هدف:
- Web UI: React + TypeScript (مهاجرت تدریجی از نمونه اولیه JavaScript) + Vite، فارسی/انگلیسی و RTL/LTR، واکنش‌گرا و قابل نصب به‌صورت PWA.
- Backend: ASP.NET Core Web API، احراز هویت و مجوزهای نقش‌محور، چندمستاجری و چندشعبه‌ای.
- Data: PostgreSQL برای سرویس مرکزی؛ SQLite برای حالت محلی/آفلاین و پایانه فروش، با همگام‌سازی کنترل‌شده.
- Modules: هسته و مجوزها، صندوق/POS، کالا و انبار، مشتریان، حسابداری، کافه/رستوران، گیم‌نت و زمان‌سنجی، سفارش آنلاین، گزارش‌ها، کاربران و شعب.
- Integrations: چاپگر رسید، بارکدخوان و PC-POS از طریق عامل/سرویس محلی امن؛ اطلاعات کارت و رمز عبور هرگز در مرورگر ذخیره نمی‌شوند.

## اصول تحویل
هر قابلیت باید همراه تست، کنترل دسترسی، اعتبارسنجی، مدیریت خطا، مهاجرت داده و مستندات تکمیل شود. نمونه نمایشی به‌معنای آماده‌بودن برای عملیات واقعی نیست.
